Présentation sur l'observabilité (o11y) et Elasticsearch. Comment Elasticsearch peut être utilisé pour collecter, stocker et analyser les données de logs, métriques et traces afin d'améliorer la visibilité et la compréhension des systèmes distribués.

Nous abordons comment Elasticsearch fonctionne : qu'est-ce qu'un moteur de recherche et pourquoi est-il si performant pour chercher n'importe quel type de données. Nous verrons ensuite comment `ES|QL` permet de facilement interroger les données stockées dans Elasticsearch et comment Kibana peut être utilisé pour visualiser ces données de manière efficace.

Enfin, nous que les données d'o11y ne sont finalement que des données comme les autres et qu'Elasticsearch est un outil idéal pour les stocker, les analyser et les visualiser, grâce à sa solution clé en main pour l'observabilité : Elastic Observability.
